# Mellow 기능 요구사항

## 상태 기준

- 미정: 요구사항을 정의하지 않은 상태
- 제안: 검토 중이며 구현 승인이 없는 상태
- 승인: 사용자 승인으로 확정된 요구사항

## 기능 목록

현재 승인된 개별 기능 요구사항은 없다. 모바일 카메라/필터 앱이라는 제품 방향만 확정되어 있다.

## 조사와 요구사항 구분

경쟁 앱의 폰트 선택, 글자 크기 조절, 영상 필터 지원 여부에 대한 조사는 참고 자료다. 해당 기능을 Mellow에 포함할지는 별도 승인이 필요하다.
