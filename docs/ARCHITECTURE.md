# Mellow 기술 구조

## 현재 상태

- 앱 프로젝트와 기능 코드는 아직 생성하지 않는다.
- 프레임워크, 언어, 저장 방식, 서버 구성은 선택하지 않았다.
- 대규모 architecture 변경은 사용자 승인이 필요하다.

## 결정할 기술 사항

| 항목 | 상태 | 결정 시 검토할 내용 |
| --- | --- | --- |
| 지원 OS 및 최소 버전 | 미정 | 대상 사용자, 기기 범위 |
| 앱 프레임워크 및 언어 | 미정 | 카메라·필터 요구사항, 플랫폼 지원, 유지보수 |
| 카메라 및 이미지·영상 처리 | 미정 | 실시간 처리 여부, 품질, 성능 |
| 데이터 저장 | 미정 | 저장 대상, 보존 및 삭제, 기기 내 저장 여부 |
| 서버 및 계정 | 미정 | 제품 요구에 따른 필요성 |
| 외부 라이브러리 및 서비스 | 미정 | 필요성, 라이선스, 비용 |
| 권한 및 개인정보 처리 | 미정 | 실제 기능에 필요한 접근 범위 |
| 성능 목표 | 미정 | 처리 지연, 메모리, 배터리, 출력 품질 |
| 배포 및 CI | 미정 | 지원 플랫폼, 검증 및 배포 절차 |

| --- | --- | --- |
