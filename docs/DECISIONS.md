# Mellow 결정 기록

## 기록 원칙

- 승인된 결정과 미정 의제를 구분한다.
- 제안은 사용자 승인 전까지 확정으로 기록하지 않는다.
- 기존 결정 변경 시 이전 기록을 보존하고 변경 이유와 승인 근거를 남긴다.

## D-001 — 프로젝트 기반 준비

- 날짜: 2026-09-10
- 상태: 승인
- 승인 근거: 프로젝트 기반 준비에 대한 사용자 요청
- 결정:
  - 제품명은 Mellow이며 모바일 카메라/필터 앱을 처음부터 개발한다.
  - 현재 단계에서는 `AGENTS.md`와 `docs/`의 제품 개발 문서 템플릿을 준비한다.
  - Git 저장소가 없으면 초기화한다.
  - 앱 프레임워크와 실제 기능 코드는 아직 생성하지 않는다.
  - 미확정 제품 및 기술 사항은 임의로 결정하지 않는다.
- 영향: 구현은 후속 요구사항과 기술 선택에 대한 결정 이후 진행한다.
