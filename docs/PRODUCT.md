# Mellow 제품 정의

## 확정 사항

- 제품명: Mellow
- 제품 유형: 모바일 카메라/필터 앱
- 개발 방식: 처음부터 개발
- 현재 범위: 프로젝트 기반 문서 준비. 앱 프로젝트와 실제 기능 구현은 아직 시작하지 않는다.

## 제품 배경

- 샤디(Shardee)를 참고하되 차별화된 앱을 만들고자 한다.
- 샤디의 기능이나 이전 조사 결과는 Mellow의 확정 요구사항이 아니다.
