# 2-12a 실기기 검증 절차 (iPhone 12 · Xcode 콘솔)

세션 닫기(2-12a)의 실기기 게이트다. 가드·성공·실패·되돌림·읽기 전용은
하네스 N군이 스텁 파이프라인으로 값 검증하므로, 여기서 보는 것은 **실제
파이프라인이 실기기에서 끝까지 도는 것**이다 — 병합 · passthrough 익스포트 ·
사진 앱 저장 · `isClosed` 기록 · 재실행 후 유지.

**빌드 전제**: 2-12a 구현이 들어간 커밋 이상. `세션 닫기` 버튼과
`[probe] ⏹ 세션 닫힘` 블록이 있어야 한다.

## ⚠ 순서가 자유롭지 않다 — 재실행이 활성 세션을 지운다

`activeSessionID`는 `@State`라 **앱을 재실행하면 사라지고, 닫힌 세션은
이어가기 후보가 아니라 `세션 시작`으로 다시 잡을 수도 없다.** 프로브에는
세션을 id로 지정하는 수단이 없다.

그래서 **닫힌 세션을 활성으로 요구하는 항목(4·5)은 그 세션을 닫은 실행
안에서 끝내야 한다.** 이 절차가 세션을 두 개 닫는 이유다 — 첫 세션으로
2(닫기)를, 재실행을 건너 3(유지)을 보고, 두 번째 세션으로 4(가드)·5(삭제)를
본다.

## ⚠ 대상을 흐리는 두 함정

- **`전부 삭제`를 쓰지 마라.** 항목 5의 삭제는 `세션 삭제` 버튼이어야
  `SessionStore.delete`를 탄다 (2-12 절차서와 같은 이유)
- **프로브 버튼은 비활성이어도 흐려지지 않는다.** `.disabled`가 히트
  테스트만 막는다. 눌렸는지는 콘솔 블록으로만 판정한다. 단 `세션 닫기`는
  닫는 동안 라벨이 `닫는 중…`으로 바뀐다 — 재진입 방지 표시이지 판정
  근거가 아니다

## ⚠ 사진 앱 권한

파이프라인 맨 앞이 권한 확인이다(1-18 순서). 미결정 상태면 첫 닫기에서
시스템 팝업이 뜬다 — Phase 1 측정으로 이미 허용돼 있을 가능성이 높지만,
거부 상태면 항목 2가 `닫기 실패`로 끝나는 것이 **정상 동작**이다
(`permissionDenied`, 세션은 열린 채).

## 무엇으로 판정하는가

|항목|판정|근거|
|---|---|---|
|1. 클립 0개 닫기 거부|**콘솔**|`✕ 세션 닫기` + `저장할 클립이 없습니다`|
|2. 닫기 = 사진 앱 저장|**콘솔 + 사진 앱**|`⏹ 세션 닫힘  isClosed=true` + 완성본이 실제로 재생된다|
|3. 재실행 후 닫힌 상태 유지|**콘솔**|`재고`의 `이어가기=불가`|
|4. 닫힌 세션 클립 추가·삭제 거부|**콘솔**|`sessionClosed` 계열 에러|
|5. 닫힌 세션 삭제 가능|**콘솔 + 사진 앱**|`⌦ 세션 삭제` 성공 + 완성본은 남아 있다|
|6. tmp 잔여물 없음|**콘솔**|`재고`의 tmp 개수가 닫기 전후 같다|

**2번이 이 게이트의 본전이다.** 하네스는 파이프라인을 스텁으로 갈아끼웠으므로
실제 병합~사진 저장이 도는 것은 여기서만 확인된다. **이 게이트에서 유일하게
화면 밖(사진 앱)을 봐야 하는 항목이기도 하다** (2·5).

## 0. 준비 — 현재 상태를 먼저 기록한다

**기기 상태를 절차에 박지 않는다** (2-8 절차서의 교훈).

```bash
xcodegen generate
```

실기기 타깃으로 Run (Debug). **`-MellowTrace`는 넣지 마라.**

> **⚠ Xcode Run은 콘솔을 지운다.** 이 절차에는 항목 3에서 재실행이 있다.
> 로그를 남기려면:
>
> ```
> xcrun devicectl device process launch --console --terminate-existing \
>   --device <UDID> com.lunalism.mellow | tee /tmp/2-12a-device.log
> ```

### 0-1. 기준선 받아 적기

`재고 조사 — 앱 실행 직후` 블록에서:

|칸|값|
|---|---|
|세션 개수| |
|대상 세션 id| |
|└ 방향 / 컷 수| |
|└ 이어가기| |
|tmp 남은 녹화본 개수| |

**항목 1의 대상은 클립 0개 세션이다.** 2-12 게이트가 남긴
`8월 21일 세션 · 0컷`이 있으면 그대로 쓴다.

### 0-2. 대상이 없으면

|기준선|어떻게|
|---|---|
|클립 0개 진행 중 세션이 있다|**그대로 항목 1로**|
|진행 중 세션에 클립이 이미 있다|항목 1을 건너뛰고 항목 2부터. 클립 0개 거부는 하네스 N-1이 값으로 덮는다 — 실기기에서 굳이 만들려고 클립을 지우지 마라|
|세션이 없다|`세션 시작` → 0컷 상태로 항목 1|

## 항목 1 — 클립 0개 세션은 닫히지 않는다

### 조작

1. **`세션 시작`** 탭 — 0컷 세션을 잡는다 (`0컷` 확인)
2. **`세션 닫기`** 탭

### 통과 기준

```
[probe] ✕ 세션 닫기 실패  id=<대상 id> — 저장할 클립이 없습니다.
[probe]   isClosed=false  ← 실패면 false 여야 한다 (열린 채 계약)
```

- **`저장할 클립이 없습니다`** — `SessionCloseError.empty`다
- **`isClosed=false`** — 열린 채 남았다
- 사진 앱에 아무것도 추가되지 않았다 (파이프라인이 애초에 안 돌았다)

**화면**: `닫기 실패: … · isClosed=false`

---

## 항목 2 — 닫기 = 사진 앱 저장 (본전)

### 조작

1. 클립 **2~3개** 촬영 → 각각 **`클립 저장`** 탭 (컷 수가 쌓이는지 확인)
2. **`재고`** 탭 — tmp 개수를 받아 적는다 (항목 6의 기준값)
3. **`세션 닫기`** 탭 — 완성까지 수 초 걸린다 (`닫는 중…`)

### 통과 기준

```
[probe] ⏹ 세션 닫힘  id=<대상 id>
[probe]   isClosed=true  3컷  방향=<세션 방향>
[probe]   이어가기=불가 ✓
```

**화면**: `세션 닫힘 · isClosed=true`

**사진 앱을 연다.**

- 새 동영상이 하나 있다
- 재생하면 **찍은 순서대로** 이어진다 (컷 수만큼)
- 길이가 클립 합과 대략 맞다

> **⚠ 계열 내 180도 갭.** 거꾸로 들고 찍은 클립이 있었다면 그 구간이
> 뒤집혀 보인다. **버그가 아니라 알려진 갭이다** — 정규화(2-D) 이전이라
> passthrough가 픽셀을 건드리지 않는다. 2-20이 닫는다 (Tasks.md 2-12a)

### 실패하면

|증상|의심|
|---|---|
|`닫기 실패: … permissionDenied`|사진 앱 권한 거부 상태. 설정에서 허용 후 재시도 — 세션은 열린 채여야 한다|
|`닫기 실패: … 병합에 실패`|파이프라인 `.merge`. 클립 파일이 실제로 있는지 `재고`로 확인하고 보고|
|`닫기 실패: … 익스포트`|passthrough 실패. 1-18 이후 처음 보는 증상이므로 **그 자리에서 멈추고 보고**|
|`isClosed=false`인데 사진 앱에 완성본이 있다|`isClosed` 기록 실패 케이스(AC 허용 상태). 콘솔의 `저장은 됐지만 세션을 닫지 못했습니다`를 확인하고 보고 — 재닫기하면 완성본이 하나 더 생기는 것이 계약이다|
|`⏹ 세션 닫힘`인데 사진 앱에 없다|**계약 위반이다.** 성공 판정과 에셋 생성이 갈렸다 — 멈추고 보고|

---

## 항목 3 — 재실행 후에도 닫혀 있다

### 조작

1. 앱을 스와이프로 강제 종료
2. 다시 실행 (콘솔을 잡으려면 위 devicectl 명령)
3. `재고 조사 — 앱 실행 직후` 블록을 본다

### 통과 기준

```
[probe]  · <세션 이름>  id=<항목 2에서 닫은 id>
[probe]    디렉터리=있음  방향=…  메타 3컷 / 파일 3개  이어가기=불가
```

- **`이어가기=불가`** — `isClosed`가 스토어에 기록돼 재실행을 넘어왔다
- 클립 메타와 파일은 그대로다 — 닫기는 세션 내용을 지우지 않는다

추가로 **`세션 시작`** 탭 → **`+ 새 세션`**이어야 한다 (닫힌 세션은
이어가기 후보가 아니다 — 하네스 5군의 실기기 판. 이 새 세션이 항목 4·5의
재료다).

## 항목 4 — 닫힌 세션에는 클립을 넣지도 빼지도 못한다

항목 3이 만든 새 세션을 **1컷으로 빠르게 닫아** 활성 상태의 닫힌 세션을
만든다 (항목 2에서 닫은 세션은 재실행으로 활성에서 풀렸고 다시 잡을 수
없다 — 문서 상단 참고).

### 조작

1. 클립 1개 촬영 → **`클립 저장`** 탭
2. **`세션 닫기`** 탭 → `⏹ 세션 닫힘  isClosed=true` 확인
   (두 번째 완성본이 사진 앱에 생긴다)
3. 클립 1개 촬영 (녹화는 된다 — 막는 것은 저장이다)
4. **`클립 저장`** 탭
5. **`컷 삭제`** 탭

### 통과 기준

**탭 4** (클립 저장):

```
[probe] ✕ 클립 저장 — 닫힌 세션에는 클립을 추가할 수 없습니다.
```

- **화면**: `저장 실패: …`
- 촬영한 클립은 목록 개수에 남아 있다 (가드가 `adopt` 앞이라 파일이 안
  움직였다)

**탭 5** (컷 삭제):

```
[probe] ✕ 클립 삭제 — 닫힌 세션의 클립은 삭제할 수 없습니다.
```

- **화면**: `삭제 실패: …`
- `재고`에서 이 세션의 컷 수가 1 그대로다

---

## 항목 5 — 닫힌 세션도 삭제는 된다

**가드 미적용 검증이다** — 닫힌 세션의 읽기 전용에 세션 삭제는 포함되지
않는다 (PRD F-07 AC). 대상은 항목 4에서 닫은 활성 세션이다.

### 조작

1. **`세션 삭제`** 탭 (`전부 삭제` 아님)

### 통과 기준

```
[probe] ⌦ 세션 삭제  <항목 4의 id>
[probe]   디렉터리 지움  실제 확인=없음 ✓
[probe]   cascade 로 함께 지워질 클립 1개
```

**사진 앱을 다시 연다.**

- **완성본 두 편이 그대로 있다** (항목 2의 것과 항목 4의 것) — 세션
  삭제는 앱 내부 데이터만 지운다. 사진 앱의 완성본은 우리 소유가 아니다

---

## 항목 6 — tmp에 익스포트 잔여물이 없다

### 조작

1. **`재고`** 탭

### 통과 기준

- `tmp 남은 녹화본 N개` — **항목 2에서 받아 적은 기준값 + 1**이다
  (항목 4에서 저장이 거부된 촬영분 하나만 늘었다. 닫기 두 번은 아무것도
  남기지 않았어야 한다)
- 파이프라인의 `mellow-close-…` 디렉터리가 남았으면 여기서 개수가 더 는다.
  콘솔에 `[close] ✕ tmp 정리 실패`가 찍혔는지도 함께 본다 — 찍혔다면 정리
  실패가 관측된 것이니 보고 (3-17 범주지만 첫 관측은 기록한다)

## 실행 순서 요약

```
0. xcodegen generate → Run → 기준선 표 (세션 · 이어가기 · tmp 개수)
1. [세션 시작] → [세션 닫기]      → ✕ 저장할 클립이 없습니다 · isClosed=false
2. 촬영×2~3 + [클립 저장] → [재고](tmp 기준값) → [세션 닫기]
                                  → ⏹ isClosed=true + 사진 앱 완성본   ← 본전
3. 강제 종료 → 재실행 → [재고]    → 이어가기=불가 (닫힘 유지)
   → [세션 시작]                  → + 새 세션 (항목 4·5의 재료)
4. 촬영 1개 + [클립 저장] → [세션 닫기] → 촬영 1개
   → [클립 저장] / [컷 삭제]      → 둘 다 sessionClosed 거부
5. [세션 삭제]                    → 성공 + 사진 앱 완성본 두 편은 남는다
6. [재고]                         → tmp 개수 = 항목 2 기준값 + 1
```

**`전부 삭제`는 어느 단계에서도 쓰지 않는다.**

## 판정 결과를 남길 때 인용할 줄

```
[probe] ✕ 세션 닫기 실패  id=… — 저장할 클립이 없습니다.
[probe] ⏹ 세션 닫힘  id=…
[probe]   isClosed=true  N컷  방향=…
[probe]    … 이어가기=불가          (재실행 후 재고)
[probe] ✕ 클립 저장 — 닫힌 세션에는 클립을 추가할 수 없습니다.
[probe] ✕ 클립 삭제 — 닫힌 세션의 클립은 삭제할 수 없습니다.
[probe] ⌦ 세션 삭제  …  실제 확인=없음 ✓
[probe] tmp 남은 녹화본 N개
```

항목 2·5의 사진 앱 확인만 화면 밖 판정이다.

결과는 `Tasks.md`의 2-12a 항목에 기록한다. 이 문서는 절차만 들고 있다.
