# 2-12 실기기 검증 절차 (iPhone 12 · Xcode 콘솔)

세션 삭제(2-12)의 실기기 게이트다. 삭제 로직과 `.cascade`, 실패 경로는
하네스 H군이 값으로 검증하므로, 여기서 보는 것은 **실기기에서만 확인되는
것**이다.

**게이트 2의 미통과 항목 하나가 여기서 닫힌다** — "세션 삭제 후 디렉터리가
파일시스템에서 사라진다".

**빌드 전제**: 2-12 구현이 들어간 커밋 이상. `세션 삭제` 버튼과
`[probe] ⌦ 세션 삭제` 블록이 있어야 한다.

## ⚠ `전부 삭제`를 쓰지 마라

**경로가 다르다.**

|버튼|무엇을 부르나|2-12 대상인가|
|---|---|---|
|**`세션 삭제`**|`SessionStore.delete(_:)`|**이것이다**|
|`전부 삭제`|`modelContext.delete(session)` 직접|**아니다** — 저장 계층을 우회하는 초기화 수단|

`전부 삭제`로 검증하면 **2-12가 만든 코드를 한 줄도 안 타고** 통과한다.
2-8에서 하네스 9군이 `ClipStore.save`를 안 타 검증이 무력했던 것과 같은
종류다. 쓸 자리는 하나뿐이다 — 기기를 백지로 만들 때.

**`세션 삭제`는 활성 세션 하나만 지운다.** `세션 시작`으로 대상을 먼저
잡아야 하며, 안 잡으면 버튼이 눌리지 않는다(`activeSession == nil`).

## ⚠ 프로브 버튼은 비활성이어도 흐려지지 않는다

`pill(_:)`이 `Text`에 `.foregroundStyle(.white)`를 명시하고 배경을 직접
칠해서, `.disabled`가 **히트 테스트만 막고 외형은 그대로다**
(`ContentView.swift:780`). **버튼 외형으로 상태를 판정하지 마라** — 눌렸는지는
콘솔에 블록이 찍히는지로만 안다.

## 무엇으로 판정하는가

|항목|판정|근거|
|---|---|---|
|1. 세션이 사라진다|**콘솔**|`재고`의 `세션 N개`|
|2. 디렉터리가 파일시스템에서 사라진다|**콘솔**|`⌦ 세션 삭제`의 `실제 확인=없음 ✓`|
|3. 클립 메타데이터가 함께 사라진다 (`.cascade`)|**콘솔**|`재고`에 클립 줄이 없다|
|4. 삭제 후 `세션 시작`이 새로 만든다|**콘솔**|`+ 새 세션` vs `▶ 이어가기`|

**2번이 이 게이트의 본전이다.** 나머지 셋은 하네스가 이미 값으로 덮지만,
디렉터리가 **실기기 파일시스템에서** 사라지는 것은 여기서만 본다. 게이트 2의
문장이 그것을 요구한다.

**`실제 확인=`은 우리가 파일시스템에 다시 물어본 값이다.** 그 앞의
`디렉터리 지움`은 `SessionFileStore`가 돌려준 값이고, **둘이 갈리면 계약이
깨진 것이다.** 한 줄만 보고 통과로 적지 마라.

## 0. 준비 — 현재 상태를 먼저 기록한다

**기기 상태를 절차에 박지 않는다.** 2-8 절차서가 "세션 2개"를 전제로 썼다가
기기 초기화로 통째로 못 쓰게 됐다.

```bash
xcodegen generate
```

실기기 타깃으로 Run (Debug). **`-MellowTrace`는 넣지 마라.**

> **⚠ Xcode Run은 콘솔을 지운다.** 이 절차에는 재실행이 없지만, 상태를
> 바꾸려고 앱을 다시 띄우면 그때까지의 로그가 날아간다.
>
> ```
> xcrun devicectl device process launch --console --terminate-existing \
>   --device <UDID> com.lunalism.mellow | tee /tmp/2-12-device.log
> ```

### 0-1. 기준선 받아 적기

```
[probe] ═══ 재고 조사 — 앱 실행 직후
[probe] 세션 N개 (스토어 기준)
[probe]  · <이름>  id=…
[probe]    디렉터리=있음  방향=…  메타 …컷 / 파일 …개  이어가기=…
[probe]      order=0  9.xxx s  <uuid>.mov  파일=…MB
[probe] ═══
```

|칸|값|
|---|---|
|세션 개수| |
|대상 세션 id| |
|└ 방향 / 컷 수| |
|└ 디렉터리| |

**대상은 `2-10` 게이트가 남긴 `8월 19일 세션 · 1컷 · landscape`다.** 파일 ·
디렉터리 · 메타데이터가 다 있어 삭제 검증에 그대로 쓸 수 있다. **새로 만들지
마라** — 만들면 클립 0개 세션이 되어 `.cascade` 확인(항목 3)이 무의미해진다.

### 0-2. 대상이 없으면

|기준선|어떻게|
|---|---|
|세션 1개 이상, 클립 1개 이상|**그대로 항목 1로**|
|세션은 있는데 클립 0개|`세션 시작` → 녹화 → `클립 저장`으로 한 컷 채운다. `.cascade`를 보려면 클립이 있어야 한다|
|세션이 없다|`세션 시작` → 녹화 → `클립 저장`|

## 항목 1·2·3 — 세션을 지운다

세 항목이 한 번의 탭으로 판정된다. 나눠 적은 것은 **실패했을 때 무엇이
깨졌는지 가르기 위해서**다.

### 조작

1. **`세션 시작`** 탭 — 대상을 잡는다
2. **`세션 삭제`** 탭

### 통과 기준

**탭 1** — 대상이 기준선과 같은지 먼저 본다.

```
[probe] ▶ 이어가기  8월 19일 세션  id=<기준선과 같은 id>
[probe]   제목저장값=""  방향=landscape  1컷
```

**탭 2** — 이것이 이 게이트의 핵심 줄이다.

```
[probe] ⌦ 세션 삭제  <id>
[probe]   디렉터리 지움  실제 확인=없음 ✓
[probe]   cascade 로 함께 지워질 클립 1개
```

|볼 것|기대|무엇을 뜻하나|
|---|---|---|
|`디렉터리 지움`|`지움`|`removeSessionDirectory`가 `true`를 돌려줬다|
|**`실제 확인=없음 ✓`**|**`없음 ✓`**|**파일시스템에 다시 물어 확인했다 — 항목 2**|
|`cascade 로 함께 지워질 클립 N개`|`1개`|지우기 전 클립 수. 항목 3의 기준값|

**화면**: `세션 삭제 · 디렉터리=지움`

### 그다음 — `재고`로 확인 (항목 1·3)

**`재고`** 탭.

```
[probe] 세션 0개 (스토어 기준)
```

- **`세션 0개`** — 항목 1. 기준선이 1개였다면 0개여야 한다
- **클립 줄(`order=…`)이 하나도 없다** — 항목 3. `.cascade`가 클립
  메타데이터를 함께 데려갔다. 위 `cascade 로 함께 지워질 클립 1개`와 짝을
  이룬다
- **`⚠ 고아 세션 디렉터리` 줄이 없다** — 디렉터리도 실제로 사라졌다.
  항목 2의 두 번째 근거다

### 실패하면

|증상|의심|
|---|---|
|`실제 확인=⚠ 아직 있음`|**`removeSessionDirectory`의 계약이 깨졌다.** `true`를 돌려줬는데 파일이 남았다는 뜻이다. 게이트 2 문장이 여기서 막힌다|
|`디렉터리 이미 없었음`|삭제 전에 이미 없었다. 기준선의 `디렉터리=있음`을 다시 봐라 — 기준선이 틀렸거나 그 사이에 뭔가 지웠다|
|`재고`에 클립 줄이 남는다|**`.cascade`가 실기기에서 안 돈다.** 하네스 H-1·H-2는 통과하는데 여기서 남으면 Mac↔실기기 차이이므로 **그 자리에서 멈추고 보고해라**|
|`⚠ 고아 세션 디렉터리`|메타데이터는 지워졌는데 디렉터리가 남았다. 순서(메타 먼저)대로 돈 결과이고 **2-16 대상**이지만, 이번 실행에서 나오면 안 된다|
|`세션 삭제 실패:` 로그|메타데이터 단계 실패다. **세션도 클립도 디렉터리도 그대로 남아 있어야 한다** — `재고`로 확인하고 보고해라|
|버튼이 안 눌린다 (블록이 안 찍힌다)|`세션 시작`을 먼저 안 눌렀다. `activeSession`이 `nil`이다|

## 항목 4 — 삭제 후 `세션 시작`이 새로 만든다

> **덤으로 확인되는 것이다.** 세션이 0개가 되면 `startOrResume`이 이어갈
> 대상을 못 찾아 **생성 경로**를 탄다. 2-7 이후 그 경로가 실기기에서 다시
> 확인된 적이 없다 — 늘 이어갈 세션이 있었기 때문이다.

**전제**: 항목 1이 `세션 0개`로 끝났다.

### 조작

1. **`세션 시작`** 탭

### 통과 기준

```
[probe] + 새 세션  8월 21일 세션  id=<새 id>
[probe]   제목저장값=""  방향=미정  0컷
[probe]   디렉터리 …/sessions/<새 id>
[probe]   clips/ 있음=true  백업제외=true
```

- **`+ 새 세션`** — `▶ 이어가기`가 아니다
- **`id`가 방금 지운 것과 다르다**
- **`방향=미정  0컷`** — 갓 만든 세션이다
- **`clips/ 있음=true`** — 디렉터리 생성이 함께 돌았다
- **`백업제외=true`** — `sessions/`가 iCloud 백업에서 빠져 있다(2-3)

### 실패하면

|증상|의심|
|---|---|
|`▶ 이어가기`|세션이 안 지워졌다. 항목 1을 다시 봐라|
|`clips/ 있음=false`|`createSessionDirectory`가 clips 하위까지 안 만들었다. 2-6 회귀다|

## 실행 순서 요약

```
0. xcodegen generate → Run → 기준선 표를 받아 적는다 (id · 방향 · 컷 수 · 디렉터리)
1. [세션 시작]        → ▶ 이어가기, id 가 기준선과 같은지 확인
2. [세션 삭제]        → ⌦ 세션 삭제 / 디렉터리 지움 / 실제 확인=없음 ✓   ← 본전
3. [재고]             → 세션 0개 · 클립 줄 없음 · 고아 디렉터리 줄 없음
4. [세션 시작]        → + 새 세션 (이어가기가 아니다)
```

**`전부 삭제`는 어느 단계에서도 쓰지 않는다.**

## 판정 결과를 남길 때 인용할 줄

```
[probe] ⌦ 세션 삭제  <id>
[probe]   디렉터리 <지움|이미 없었음>  실제 확인=<없음 ✓|⚠ 아직 있음>
[probe]   cascade 로 함께 지워질 클립 N개
[probe] 세션 N개 (스토어 기준)
[probe] <+ 새 세션|▶ 이어가기>  …
```

전부 콘솔이다. **이 게이트에는 화면으로만 판정하는 항목이 없다.**

결과는 `Tasks.md`의 2-12 항목에 기록하고, **게이트 2의 "세션 삭제 후
디렉터리가 파일시스템에서 사라진다"도 함께 갱신한다.** 이 문서는 절차만
들고 있다.
